# LazyCode Documentation

LazyCode (working name) is a light, open-source code editor written in Go that runs in your terminal, between VS Code and Neovim. It's built around multi-directory projects, AI harness sessions, and watching AI changes live. The prototype is being built, and there's no editor yet.

## Where to start

1. Open [backlog.html](backlog.html) for progress, start order and parallel work.
2. Read [04-feasibility.md](04-feasibility.md) for memory, complexity and realism.
